# Render development

## UI work

The owner requires the `unslop-ui` skill for every UI change. Read and apply the available skill before changing any interface, including settings, dialogs, inspectors, timelines and empty states.

Keep Render restrained and native: semantic macOS colors, system typography, clear control states, consistent spacing and meaningful SF Symbols. Avoid decorative cards, gradients, glows, marketing copy and redundant branding. Preserve the editing workflow.

Review actual macOS captures in dark and light appearances, including the compact workspace. Exercise existing native interaction checks when layout changes can affect input. Do not treat a successful compile as visual validation.
