# Compound architecture

Schema 10 stores reusable CompoundSource definitions as an acyclic graph, limited to eight sources along a path. Project validation checks all IDs, source bounds, tracks, keyframes and transitions before mutations reach session state. Timeline projections include only reachable descendant definitions; context replacement merges them into the persistent root and validates the whole document.

EditorSession separates its active projection from its root document. Undo snapshots always contain root documents. Saving, recovery, duplication and video export use the root; playback and timeline commands use the active projection. Removing an open source through undo returns to a surviving context. Clipboard imports reachable definitions and relies on graph validation to reject cyclic pastes atomically.

CompoundCompositionBuilder retains the flat builder for ordinary timelines and uses its clock track for nested sequences. TimelineTimeMapping maps local seconds to global seconds, preserving each source frame rate. Each source instance receives fresh runtime render IDs. The planner recursively clips source ranges to ancestor render windows, reuses nonoverlapping AVComposition slots and keeps source asset owners alive during insertion. A boundary sweep assembles only active branches into hierarchical render instructions. SceneRenderer evaluates child canvases over transparency before parent processing.

CompoundAudioEnvelope compiles animation curves once with binary-search sampling. Leaf and ancestor volume, clip fades and transition envelopes multiply in global time. Breakpoints split keyframes/fades and preserve Hold discontinuities; varying spans use bounded ramps. Mute/solo scopes propagate independently of video visibility. Proxy resolution and original-audio/final-export behavior match flat sequences.

Compound creation preserves selected layer order and rejects cross-boundary transitions. Break-apart rejects group-dependent operations that cannot be represented by independent clips. Source duration is retained on deletion and expands on extension; instance trims remain independent. Tests and installed-app checks cover persistence, cycle rejection, navigation undo and real nested decoding/encoding.
