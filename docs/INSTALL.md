Render — Apple Silicon

Requires macOS 14 or newer and an Apple Silicon Mac.
Drag Render.app to Applications, then open it from Applications.

This early release is ad-hoc signed, not Developer ID signed or notarized.
macOS may require an explicit approval in System Settings > Privacy & Security.
Only approve a download obtained from the official repository's release page:
https://github.com/Ninnja10563/Render/releases

Source media is referenced in place. Keep original media backed up.
Projects use .renderproject JSON files. Recovery copies live in
~/Library/Application Support/Render/Recovery.renderproject.

See README.md in the source repository for supported workflows and limitations.
