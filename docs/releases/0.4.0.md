# Render 0.4.0 — Animation authoring

- Edit keyframe times and values in the Animation inspector. Choose Linear, Ease In, Ease Out, Ease In/Out or Hold for the outgoing segment.
- Select, remove, copy and paste keys while retaining their relative timing and interpolation. Paste aligns the first copied key to the playhead; it rejects animation extending beyond the visible clip. Moving onto an occupied frame reports an error instead of losing a key.
- Animate every existing effect's amount directly with inspector diamonds; animated controls display the value at the playhead.
- Previous/next navigation, per-key navigation, dimmed out-of-trim keys and a bounded key list support detailed work on trimmed clips.
- Editing a keyed value now preserves the key's identity and interpolation.
- All animation edits use validated timeline transactions and the existing UndoManager. Existing schema-1 projects remain compatible.

Validation includes Debug and Release core/media tests, animation transaction and serialization regressions, animated exposure preview/export pixel comparison at three frames, and installed-app editing/undo/launch smoke checks. The ARM64 Release DMG is mounted, checked and installed before publication.

Apple Silicon, macOS 14+. Ad-hoc signed; not notarized. This is a development prerelease, not a production-quality NLE. See the repository's manual checklist and current limitations for remaining workflows and physical-device verification.
