# Render 0.26.0 — Workspace refinement

A restrained native UI cleanup across the editing workspace, source viewer, inspectors and dialogs.

- Consistent panel headers, system typography and semantic macOS surfaces. The light timeline now uses a clean canvas instead of a muddy background; headers and track lanes remain distinct in both appearances.
- Timeline lanes and the ruler fill wider windows.
- Clear Source/Timeline selection with Source disabled when no media is selected, better-spaced viewer controls and accessible transport labels. Shortcut hints continue to reflect custom bindings.
- Numeric inspector values use visible native text fields. Secondary metadata is more readable, and empty searches explain their result.
- Multicam setup has explicit column labels and a bounded camera list.
- Removed redundant toolbar branding, decorative empty-state icons and promotional copy. Compound navigation and inspector explanations are shorter, with detailed guidance retained in help.
- Added repository instructions requiring the unslop-ui skill for every future UI change.

Validation retains the existing core/media tests, DSP sanitizers, native editing and keyboard checks. Installed-app captures now cover compact and wider editing workspaces, audio, export, multicam setup and empty states, alongside source and shortcut views, in both appearances. These VM captures support visual review; physical monitor, accessibility and long-session qualification remain ongoing.

Apple Silicon, macOS 14+. Ad-hoc signed development prerelease, not notarized. Project format and editing commands are unchanged.
