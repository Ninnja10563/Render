# Render 0.19.0 — Editing workspaces and preview quality

- A searchable, categorized effects browser applies stackable effects to selected visual clips in one undoable document edit. Parameter, mask and keyframe controls remain in the inspector.
- A separate audio-controls pane exposes selected-clip volume/fades and per-track mute/solo. It can stay open beside the timeline while the inspector is hidden.
- Workspace presets provide Editing, Effects, Audio and Viewer Only layouts. Media, effects, inspector, audio and timeline panels can each be shown or hidden, with native resizable split views.
- Full, Half and Quarter preview resolution change the compositor render target independently of Original/Proxy/Optimized source selection. Project state and export dimensions remain unchanged.

Native checks exercise effect application and undo, workspace switching, and reduced-resolution playback. Media integration checks compare flat and nested composition geometry at all preview sizes and verify full-size final export.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. This audio pane exposes existing clip/track controls; live metering, pan/channel routing and audio processors are separate work. No project schema change.
