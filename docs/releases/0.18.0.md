# Render 0.18.0 — Editable compound timelines

- Create a compound from selected clips with Timeline → Create Compound Clip (⌥⌘G), retaining the original media references and editable tracks.
- Open a compound from the Timeline menu, clip context menu or inspector. Breadcrumbs return to its parent or the project timeline. Editing the source updates every instance.
- Nested playback and export share a recursive composition planner. Source handles, child frame rates/canvas sizes, parent speed, effects, transforms, opacity, transitions and multiplied audio automation remain live; no intermediate movies are baked.
- Save, recovery, duplicate and export retain the full project while an inner timeline is open. Undo/redo restores the root document across navigation. Cyclic nesting and nesting deeper than eight sources are rejected.
- Break Apart restores independent child clips when their appearance and sound can be preserved. Group processing, mismatched sequence settings and transitions crossing a trim boundary report an actionable error instead of silently discarding changes.
- Compound clips support the existing timeline selection, movement, trimming, splitting, speed, clipboard, animation and effect operations. Nested proxy previews retain original-only final export.
- Exact-frame tolerances make the multicam preview/export comparison deterministic.

Schema 10 adds optional compound source definitions; existing projects migrate on load. Older Render versions cannot read newly saved schema-10 projects. Source duration remains available when inner clips are deleted, and grows when the source is extended; existing instance durations remain independent.

Validation includes graph cycles/depth, context replacement, magnetic grouping, serialization, structural undo, nested timing/audio/transition rendering, real encoded preview/export parity, proxy fallback and an installed-app navigation/save/undo/break-apart check. Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. Compound thumbnails/waveforms are not yet flattened into timeline summaries, and physical-device performance/manual usability validation remains outstanding.
