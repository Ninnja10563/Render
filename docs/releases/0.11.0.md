# Render 0.11.0 — Cut transitions

- Cross Dissolve, Fade Through Transparent, Dip to Black, Dip to White, Wipe and Slide between adjacent clips, with editable durations and timeline indicators.
- Transitions span both sides of the cut without changing sequence length. Moving video requires real source handles; missing handles produce an actionable error rather than frozen or invented frames.
- Playback and export decode overlapping source ranges on reusable composition slots. Paired rendering retains clip transforms, effects, opacity and blend modes.
- Audio crossfades over the same interval while preserving volume automation.
- Structural edits remove broken transition pairs in the same undoable operation. Single-track and multitrack paste remap copied transition targets.
- Schema 7 stores transition links; earlier project schemas migrate unchanged.

Validation includes Debug/Release core tests, all six transition endpoints/midpoints, real encoded-video handles, preview/export comparisons across each cut, aligned-tone audio level checks, and installed-app transition/undo/playback checks. ARM64 Release DMG installation is verified before publication.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. Transition duration cannot exceed either adjacent clip. Independent audio-transition timing/curve controls and physical-device/manual workflow verification remain outstanding.
