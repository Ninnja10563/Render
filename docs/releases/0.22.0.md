# Render 0.22.0 — Clip audio processors

Render gains ordered, non-destructive audio effect stacks: three-band EQ, compressor, sample peak limiter, and noise gate. Add processors in the Inspector or Audio panel, adjust their parameters, bypass, reorder, reset, and remove them with normal project undo/redo.

The same native processing taps supply playback and export. Effects run before clip volume and fades, retain stereo/multichannel relationships, and reset state after discontinuous seeks. Playback meters display the processed signal with the clip fader applied. Export processing failures are reported before publishing the output file.

Project schema 11 stores audio processors. Earlier projects remain readable. Effects apply to source clips with one through eight channels; open compound timelines to process their sources. Parameters are static in this release. The limiter measures sample peaks, not intersample true peaks; subsequent fader gain or mixing can increase the final level. The gate attenuates quiet material rather than performing spectral noise removal.

Validation includes portable DSP numerical tests with sanitizers, project validation/serialization/detach tests, native reader and codec export comparisons, and installed-app playback checks.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease.
