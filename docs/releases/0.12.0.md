# Render 0.12.0 — Clip audio fades

- Fade-in and fade-out durations with Linear, Smooth and Equal Power curves in the inspector.
- Fades multiply volume keyframes and transition crossfades in the shared playback/export audio mix.
- Splitting and trimming retain the original envelope phase; editing a fade reattaches its envelope to the selected clip’s edges.
- Undo/redo and project serialization retain fade settings. Schema 8 migrates earlier projects with fades disabled.
- Generated titles, still images and silent video no longer show irrelevant audio controls.
- Corrected overlapping crossfade ramps whose endpoints both reached silence.

Validation includes core envelope, split, trim, undo snapshot and serialization tests, plus real encoded audio exports for every curve before and after splitting. Native Debug/Release tests and the installed ARM64 application run before publication.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. Pan, channel routing, live meters, audio processing effects and synchronization remain under development. Physical-device workflow checks remain outstanding.
