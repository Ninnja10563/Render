# Render 0.28.0 — Automatic updates

Render can now check for and install future development releases without a manual DMG download.

- Automatic daily checks and background downloads, with installation on quit. Both settings can be changed in Settings → Updates.
- Render → Check for Updates… provides the native update, download, progress and relaunch flow.
- Updates use Sparkle 2.10.0, pinned in Swift Package Manager. Both the update feed and downloaded archive are signed with Ed25519; archive validation happens before extraction.
- Save/discard prompts and running-export protection remain part of quitting for an update.
- Release automation publishes a signed feed only after its matching GitHub Release and DMG exist. Build versions now use semantic versions consistently across local, CI and release builds.

Update integration checks use disposable app copies and test signing keys: forged feed rejection, corrupt download rejection, actual installation, code-signature verification and current-version detection. Existing core/media, native interaction and installed-app checks remain required.

Install this version manually once to enable updates from future releases. Earlier Render versions do not contain an updater. This feed carries development prereleases, not production-qualified releases. Apple Silicon, macOS 14+. The app remains ad-hoc signed and not notarized; update signatures do not replace Apple Developer ID signing.
