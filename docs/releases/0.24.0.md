# Render 0.24.0 — Source viewer and range editing

Open imported media in the Source viewer to review it before editing. It has its own player, scrubbing, frame steps, J/K/L transport and in/out marks. Source playback never moves the timeline playhead. Video and audio use original media; still previews decode asynchronously at up to 2048 pixels.

- I marks In; O marks Out including the displayed frame. Clear Marks restores the full source. Times use the sequence frame rate.
- Append, Insert and Overwrite use the selected source interval. Browser append/drop operations respect the same marks; existing timeline clips retain their original source bounds.
- Marks are saved with media references in project schema 12, support undo/redo, survive relinking, and do not rebuild timeline playback when changed.
- Rejected drag starts no longer leave a stale destination preview.
- Switching back to Timeline or opening a different document stops source playback. Reverse fallback is explicitly indicated and muted.

Validation covers range bounds, fractional-rate frame counts, all three editing operations, persistence/migration, decoded preview/export frame comparisons, and an installed native source viewer playing actual audio independently of timeline transport. Installed-app workflows and screenshots now run in both dark and light appearances.

Apple Silicon, macOS 14+. Ad-hoc signed development prerelease, not notarized. A selection must contain at least one complete sequence frame to insert it.
