# Render 0.14.1 — Preserve focused inspector edits

- Save and document-close checks synchronously commit pending numeric inspector edits before taking a project snapshot.
- Invalid numeric drafts block saving with a useful message. Keyframe fields commit when focus changes and participate in save flushing.
- Extreme title/transition time entries report validation errors before integer conversion.
- Detaching embedded audio preserves its clip fade envelope.
- Export preparation also flushes inspector drafts before capturing the project.

Installed-app validation now types into a real native field editor, saves without pressing Return, reopens the file to verify the value, checks invalid-input rejection, and verifies undo. Full Debug/Release suites and DMG installation checks still run.
