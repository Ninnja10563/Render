# Render 0.20.0 — Live audio input meters

- The Audio workspace measures decoded playback samples through AVFoundation audio taps, applying the exact compiled clip/ancestor volume and fade ramps to the measurements.
- Each composition input shows channel peak and RMS levels in dBFS, with clipping indication and peak decay. Labels follow the current clip as composition tracks are reused.
- A timestamped, fixed-capacity measurement ring aligns decoding-ahead measurements with the playhead. The audio callback performs no allocation, locking, file I/O or UI dispatch.
- Meter state is isolated from document and timeline view updates. Export does not allocate playback meters or alter audio samples.

Meters show separate composition inputs, not the summed master output; nested sources can contribute several inputs. Up to eight decoded Float32 channels per input are shown. Pan, channel routing, master metering and audio processors remain separate development work.

Validation reads real stereo PCM through flat and nested AVFoundation mixes, checks post-volume peak/RMS values, and verifies metering leaves output samples unchanged. Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. No project schema change.
