# Render 0.5.0 — Chroma key and effect masks

- Chroma key with selectable screen colour, similarity, edge softness and spill suppression. Similarity can be animated through the existing effect curve workflow.
- Rectangle, ellipse and custom polygon masks for individual effects. Edit position, independent dimensions, feather, expansion and inversion; drag polygon vertices and add/remove points.
- Masks follow the clip transform and blend the effect with the original image. Use a masked Opacity effect to create transparent cutouts.
- Additional Highlights, Shadows, Temperature, Tint and Opacity effects, plus complete per-effect reset.
- Extracted shared effect renderer with bounded chroma lookup and mask caches. Pixel processing uses the Metal-backed Core Image context for both preview and export.
- Schema-1 projects migrate to schema 2 on load; edits and curves are preserved. Opening does not rewrite the original document. Saved schema-2 projects need Render 0.5 or later.
- Reject extreme animation offsets before they can overflow editing arithmetic.

Validation includes Debug and Release tests, schema migration/serialization, keyer alpha, mask geometry/feather/expansion/inversion/transform tests, real encoded masked-key preview/export comparison, and installed-app mask/undo/playback smoke checks. The ARM64 Release DMG is mounted, checked and installed before publication.

Apple Silicon, macOS 14+. Ad-hoc signed; not notarized. Development prerelease. Mask rasters are capped at 1024 pixels before scaling; keying uses a 32³ lookup. Matte cleanup/tracking, mask animation, advanced color management and physical-device performance profiling remain outstanding. See the repository's manual checklist for remaining editor workflows.
