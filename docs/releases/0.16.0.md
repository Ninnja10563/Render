# Render 0.16.0 — Vertical timeline virtualization

- Track headers and clip lanes now share a visible-row range with two rows of prefetch on either side.
- Offscreen tracks release their clip/filmstrip views, cancelling view-owned frame requests while retaining bounded reusable caches.
- Explicit spacers preserve full timeline geometry, row alignment, scroll position and the playhead across large track lists.
- Existing horizontal clip and filmstrip culling remains in place.

Tests cover 10,000-track windows, partial rows, top/bottom overscroll, invalid viewport inputs and visible-row coverage throughout scrolling. Installed-app validation creates 500 tracks, scrolls the native view to track 250, and checks that at most twelve lane views remain active and the original rows are released. Native Debug/Release tests run before publication.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. This bounds view construction and frame requests; it is not a claim of measured playback FPS or physical-device GPU performance. Large-project manual scrolling/dragging and Instruments profiling remain required.
