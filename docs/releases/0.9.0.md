# Render 0.9.0 — Transform and compositing controls

- Independent X/Y scaling, source-relative anchor points and four-sided crop, all with keyframes and reset controls.
- Horizontal/vertical flips and Normal, Multiply, Screen, Overlay, Add, Darken and Lighten blend modes.
- Crop removes pixels without reframing; a fully cropped layer becomes transparent. Anchor changes preserve unscaled placement while subsequent transforms pivot around the anchor.
- True 100% viewer mode maps one sequence pixel to one physical display pixel. Includes 200%/400%, drag-to-pan, Fit and backing-scale updates when moving between displays.
- Numeric inspector fields commit on focus loss as well as Return. Property edits explicitly target their originating clip, avoiding edits to a newly selected clip when focus changes.
- Audio-only clips no longer expose visual transform/effect sections. Core animation ranges are shared across validation and authoring.
- Schema 6 adds optional geometry; prior project schemas retain their original visual defaults.

Validation covers Debug/Release geometry/keyframe/serialization tests, anchor placement, flip/crop bounds, actual blend pixels, cropped/flipped preview/export comparison, and installed-app property-targeting/undo/playback checks. The ARM64 Release DMG is installed and verified before publication.

Apple Silicon, macOS 14+. Ad-hoc signed and not notarized. This remains a development prerelease, not a production-quality NLE; the version number does not indicate completion of all requested workflows. See the manual checklist and development plan for remaining work.
