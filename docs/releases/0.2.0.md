Render 0.2 adds deeper timeline editing to the native Apple Silicon foundation.

### New editing tools
- Ripple trims shift following clips while preserving source bounds.
- Roll edits adjust adjacent clip boundaries without changing sequence duration.
- Slip edits change the source window; slide edits move a clip while trimming its neighbors.
- Range selection supports partial-clip deletion and ripple deletion across clips and gaps.
- Overwrite editing preserves surviving media on either side of the replaced interval.
- Audio detach retains timing, speed and volume automation without duplicating source files.
- Multitrack clipboard preserves relative synchronization and track assignments.
- Live trim outlines, group movement previews and a dedicated zoom tool.

All new operations participate in the same validated transaction and macOS undo system. Regression tests cover neighboring source offsets, fixed sequence boundaries, range splitting and locked-track rollback. Installed-app validation now exercises roll, ripple trim and range delete as well as import, split, undo/redo, transforms, animation and playback.

### Download
Apple Silicon, macOS 14+. Open `Render-0.2.0-Apple-Silicon.dmg` and drag Render to Applications. SHA-256 checksum included.

### Release status
Early development release. Ad-hoc signed, not Developer ID signed or notarized. Automated macOS rendering and launch checks pass; physical-device performance profiling and human editing checks remain outstanding. Proxies, magnetic/connected and compound clips, multicam, titles/captions, transitions, masks/chroma key, advanced audio and speed ramps remain planned. See `docs/EDITING.md` for precise tool behavior and limitations.
