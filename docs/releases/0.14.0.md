# Render 0.14.0 — Export quality controls

- H.264 and HEVC exports offer Compact, Balanced, High and Custom Bitrate quality choices, alongside the existing codec-managed path.
- Resolution, frame rate and codec inform preset target bitrates; custom targets accept 0.5–200 Mbps. The export sheet shows an approximate file size and the finished output size.
- A background AVAssetReader/AVAssetWriter pipeline uses the existing GPU compositor and audio mix, requests hardware encoding, and respects encoder backpressure.
- Controlled-bitrate exports include stereo AAC at 48 kHz / 320 kbps. ProRes retains its codec-managed export path.
- Cancellation removes staging files, and completed outputs are published only after encoding finishes.
- Opening export now preserves custom sequence dimensions.

Validation covers bitrate bounds/presets, H.264 and HEVC output dimensions/frame rate/compositing/audio level, and cancellation cleanup. Native Debug/Release tests and installed-app launch checks run before publication.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. Bitrates and file sizes are targets, not guarantees. HDR mastering, multichannel routing, multipass encoding and physical-device performance profiling remain outstanding.
