# Render 0.25.0 — Editing shortcut customization

Settings → Shortcuts now provides a searchable list of transport, timeline and source commands. Record a new binding, clear it, restore an individual command, or restore all defaults. Changes persist on this Mac independently of project files.

- Assign letters, numbers, left/right arrows, Space, Home, End and Delete, optionally with Shift, Control or Option.
- Conflicting assignments are rejected without replacing existing bindings. Source-only and timeline-only commands can share keys; transport assignments apply to both viewers.
- Standard Command menu shortcuts remain native. Escape always cancels a timeline drag or closes source mode. Shortcuts do not run in text fields, sheets, dialogs or other app windows.
- Held frame-navigation keys repeat; held toggles and editing commands do not repeatedly mutate the project. Forward Delete and Backspace use the same Delete binding.
- Viewer and tool help reflects customized shortcuts. Invalid saved preferences fall back to defaults with an explanation in Settings, retaining the saved data until explicitly changed.

Core tests cover context conflicts, reassignment, serialization and corrupt preferences. Installed-app checks send native keyboard events through the actual monitor, exercise source/timeline routing and text focus, test recording, and capture the Settings interface in both appearances.

Apple Silicon, macOS 14+. Ad-hoc signed development prerelease, not notarized. Native document/menu shortcuts are not customizable in this milestone; macOS may reserve some system-wide key combinations before Render receives them.
