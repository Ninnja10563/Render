# Render 0.21.1 — Leading source handles

- Leading trims, reverse rolls and slides can reveal available source handles even when the clip's animation offset starts at zero.
- Property/effect keyframes and audio fade coordinates translate together, retaining their original phase over the existing material. Connected clips retain their content-relative timing, including ripple edits and locked-track checks.
- Generated titles, gaps and still images can extend to an earlier timeline position without an artificial negative source-in error.
- Compound clips support slip edits within their stored source bounds.

Tests compare property, effect and fade values across the retained interval, verify serialization/undo snapshots, exercise roll/slide/ripple connections and locks, and reject real source overruns. Existing project schema and media files remain unchanged.
