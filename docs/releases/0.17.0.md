# Render 0.17.0 — Hierarchical compositing foundation

- The shared compositor now evaluates a typed render graph with media leaves and nested groups.
- Child tracks composite over transparency before parent crop, transform, effects, opacity and blend mode apply, preserving group semantics.
- Nested source-time mapping and parent animation clocks remain separate; transitions can pair grouped images.
- Scene evaluation, render instructions and AVFoundation request handling are separated into focused modules. Rendering stays within the Core Image/Metal graph without intermediate encoded files or CPU pixel readback.

New tests check parent opacity isolation, nested retiming, animation, effects, group transitions, hierarchy limits and real grouped-preview/encoded-output parity. The complete existing editing/media suite and installed-app checks still run before publication.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. This is a rendering architecture milestone. User-facing compound creation, nested timeline navigation and break-apart editing are not yet exposed; no decorative compound controls have been added. No project schema change.
