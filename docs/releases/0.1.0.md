Render's first native Apple Silicon editing release establishes the project, timeline and rendering foundation.

### Editing
- Resizable native media browser, viewer, inspector and multitrack timeline.
- Video/audio/still import, asynchronous posters and waveforms, metadata and source relinking.
- Frame-based split, trim, move, insert, clipboard, ripple delete, snapping and markers.
- Track lock, visibility, mute and solo; unified macOS undo/redo.
- Transform, opacity, volume, speed, property keyframes and seven stackable image effects.

### Reliability and output
- Versioned non-destructive projects, atomic saves, recent projects and unsaved-edit recovery.
- Shared Metal-backed Core Image composition for preview and H.264/HEVC/ProRes export.
- Cancellable export with progress, elapsed/estimated time and protected source files.
- Core logic and synthetic-media integration tests; Release bundle, verified disk image and installed-copy launch smoke check.

### Requirements and limitations
Apple Silicon, macOS 14+. Early development release, not production-ready. Ad-hoc signed; not Developer ID signed or notarized. Gatekeeper may require explicit approval through Privacy & Security. Automated launch/render checks do not substitute for human editing and hardware performance validation.

Proxies, magnetic timelines, compound clips, multicam, transitions, titles/captions, masks/chroma key, speed ramps, advanced audio and full filmstrips remain planned. SDR composition only. See the repository's manual test checklist and development plan for precise scope.

Download `Render-0.1.0-Apple-Silicon.dmg`, open it, then drag Render into Applications. A SHA-256 checksum is attached alongside the image.
