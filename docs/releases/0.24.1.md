# Render 0.24.1 — Source transport navigation

Opening a compound or returning to its parent now closes and pauses the source viewer. This prevents source transport and keyboard focus from remaining attached to the previous timeline context. Source marks use the displayed source time base, and inactive source controls cannot edit the project.

The installed-app workflow checks a 24 fps compound inside a 30 fps project, source marks, returning to the parent, and reopening the compound. Both native appearances run the check. Launch validation also waits for actual timeline playback progress before capturing the workspace. Existing projects and source media remain unchanged.

Apple Silicon, macOS 14+. Ad-hoc signed development prerelease, not notarized.
