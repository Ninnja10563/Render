# Render 0.23.0 — Cross-track dragging

- Drag a clip or selection horizontally and vertically between compatible tracks. Relative lane spacing is retained in multitrack selections.
- Destination outlines and a compact status message show the proposed move; incompatible tracks, locks, overlaps and out-of-bounds drops are rejected before changing the project.
- Connected children follow their anchor's horizontal displacement. Moving an anchor out of the primary storyline clears connections that no longer have a primary anchor. Moving onto the magnetic primary packs the storyline normally.
- Escape cancels a drag. Completed moves use one document undo operation and preserve source timing, animation, effects and clip identities.
- Drag state is separate from document/playback state; stationary destination intervals use binary search, and only visible ghost clips are drawn.

Core tests cover groups, bounds, source/destination locks, overlaps and magnetic connections. The installed-app check sends native mouse events across lanes and verifies the resulting time/track, undo/redo and cancellation.

Apple Silicon, macOS 14+. Ad-hoc signed development prerelease, not notarized. Dragging outside the visible viewport does not yet auto-scroll; scroll to the destination first.
