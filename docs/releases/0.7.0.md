# Render 0.7.0 — Titles and captions

- Native generated title and caption clips with editable text, installed fonts, font weight/size, alignment, colour, outline, shadow, background and padding.
- Titles share timeline trim/split/move/copy/paste, transforms, opacity, effects, masks and keyframes. Text edits immediately participate in project history and recovery.
- Import UTF-8 SRT with BOM/CRLF, Unicode and multiline text. Overlapping cues use separate caption tracks without changing their timing. Edit caption start/duration in the inspector or timeline.
- Export visible caption tracks as SRT text/timing. SRT does not preserve Render styling; imported inline markup is reduced to plain text.
- Core Text rendering with bounded active-title raster caching. Generated clips are embedded project data and need no placeholder media files.
- Fix export resolution changing clip position/effect size: rendering retains sequence coordinates and scales the final composition into the output, letterboxing differing aspect ratios.
- Schema 4 introduces optional clip media IDs and embedded title content; previous project schemas migrate with their existing sources and edits preserved.

Validation covers Debug/Release tests, title raster transparency/text coverage, SRT malformed-input and Unicode/fractional-rate round trips, overlapping cue layout, title serialization/editing, real title export at another resolution, and installed-app title/caption/undo/playback smoke checks.

Apple Silicon, macOS 14+. ARM64 Release DMG, ad-hoc signed and not notarized. Development prerelease. Font availability affects text layout; title rasters are limited to 128 MB each. Automatic transcription and physical-device/manual workflow verification remain outstanding.
