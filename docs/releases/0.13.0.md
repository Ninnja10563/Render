# Render 0.13.0 — Audio synchronization

- Select two media clips and choose Timeline → Synchronize Audio. Pick the reference, analyze their recorded sound, review the offset and apply an undoable alignment.
- Background RMS analysis preserves stereo energy, honors source in-points and compares normalized envelopes independently of recording gain.
- Silence, repeating patterns and weak or ambiguous matches report errors instead of moving clips.
- Alignment validates source speed, track locks, timeline bounds, collisions and unchanged project state before applying.

Tests cover both offset directions, recording gain/noise, ambiguous signals, decoded stereo files with source in-points, and the resulting edit transaction. Native Debug/Release tests and installed-app launch checks run before publication.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized; development prerelease. Analyzes the first two minutes of each selected edit within ±30 seconds at 10 ms resolution, rounded to project frames. Requires separate unlocked tracks, traditional timeline mode and 100% speed. This does not correct clock drift or synchronize timecode; noisy field recordings still need manual review. No project schema change.
